KOINOUS POC — ONE-COMMAND LIVE DEMO

1. Install Node.js 22.16 or newer (with npm).
2. Extract this bundle fully. Open a terminal in koinous-poc/.
3. Run:

   npm run demo:live

The command installs pinned dependencies (internet required), checks your existing
Codex and Claude subscription logins, opens missing provider login flows, then
starts the live UI. Complete browser sign-ins with your own ChatGPT and Claude
subscription accounts. No API-key fallback; Grok stays off. Do not share credentials.

Open the localhost URL printed in the terminal (normally http://127.0.0.1:3030).
Select models available to your subscriptions. Last tested: Codex gpt-6-astra and
Claude claude-opus-5-5. Keep three rounds for a six-call discussion. Paste your idea
and click Start discussion. Setup itself sends no model prompt; Start discussion
uses your subscription quota. Stop with Ctrl+C to disable inference again.

TROUBLESHOOTING
- Run npm run demo:live -- --help for offline help.
- Dependency install requires internet and replaces node_modules each time, so
  packages match this machine. Never copy node_modules between operating systems.
- Login fails: rerun when ready or use npm run setup -- login codex / login claude.
  Unknown or API-key login methods are refused before live startup.
- Port occupied: macOS/Linux: PORT=3031 npm run demo:live
  PowerShell: $env:PORT='3031'; npm run demo:live
- Only localhost is exposed; screen-share the demo. No VM or Grok setup is needed.
- Subscription cost may remain unknown; provider estimates are not invoices.
